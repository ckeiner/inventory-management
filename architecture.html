Data Flow

1
User Interaction: User selects filters in FilterBar component (Time Period, Warehouse, Category, Status)
2
State Management: Filters stored in useFilters() composable (singleton pattern)
3
API Request: Views call api.js methods (getInventory, getOrders, etc.) with current filters
4
HTTP Communication: Axios sends GET request with filters as query parameters to backend
5
Backend Processing: FastAPI endpoint applies filters via apply_filters() function on in-memory JSON data
6
Validation: Pydantic models validate and serialize filtered results
7
Response: Backend returns JSON response with filtered data
8
Rendering: Views store response in reactive refs (allOrders, inventoryItems), computed properties transform for display
9
UI Update: Vue reactivity system updates DOM, components re-render with new data

Key Features & Patterns

🔍 Universal Filter System

4-filter system (Time Period, Warehouse, Category, Status) applies across all views. Filters managed in singleton composable, query parameters synced with backend.

📱 Responsive UI

Vue 3 components with scoped CSS styling. Design system: slate/gray colors (#0f172a, #64748b, #e2e8f0) with status indicators (green/blue/yellow/red).

📊 Real-Time Charts

Custom SVG charts and CSS Grid layouts. Dashboard shows key metrics: inventory value, low stock items, pending orders, backlog count, order value.

🌐 Internationalization

i18n support for English and Japanese. Language switcher component for changing UI language.

⚡ Composition API

Modern Vue 3 patterns with composables for shared state, auth, and translations. Easy to test and refactor.

✅ Type Safety

Pydantic models validate all API responses. FastAPI auto-generates Swagger UI documentation at /docs endpoint.

Getting Started

Quick Start (Both Servers):

./scripts/start.sh    # Starts frontend (3000) + backend (8001)

Manual Startup:

Backend:
cd server && uv run python main.py
Frontend:
cd client && npm install && npm run dev

Useful URLs:

  • 🌐 Frontend: http://localhost:3000
  • 📡 API: http://localhost:8001
  • 📚 API Docs: http://localhost:8001/docs
